# PLATEAU AWARD 2026 募集要項【一般部門】— 要点の転記

出所: https://www.mlit.go.jp/plateau-next/assets/awards/pdf/public_application-requirements_2026.pdf(2 ページ。2026-09-03 に原文から転記)。自治体共創部門の要項は別文書で、本書には含まれない。

## 1. 募集内容(3 区分)
- 【ビジネス・プロダクト提案】事業化や社会実装を目指す具体的なビジネスプラン・プロダクト提案
- 【アイデア・アプリ提案】3D都市モデルを活用した自由な発想によるアプリ、Webサービス、アイデア作品
- 【ソリューション提案】3Dデータやシミュレーションを活用した地域課題解決・都市計画ソリューション

## 2. 募集対象
- 個人または企業、教育機関・研究機関、行政機関、その他団体等のチーム。人数・年齢の制限なし(未成年は保護者の同意)。
- **同一人物・チームによる複数アイデアの応募も可能。**

## 3. 応募方法・提出事項(応募フォーム https://form.run/@plateauaward2026-apply)
- 応募者情報(氏名・代表者名、メールアドレス、住所、電話番号、所属団体・企業等)
- 作品タイトル
- 作品概要(**概要、対象ユーザー、解決する課題、PLATEAU データの活用方法** 等)
- 添付資料 1. プレゼン用スライド資料(**10MB までの PDF**) 2. 作品の動作などがわかる動画(**時間制限: 3 分間**)

※ 要項の提出事項に「動作環境」の項目は無い(フォーム側にある可能性はあるので提出時に確認)。

## 4. 表彰
- グランプリ 1 作品(**最も将来性のある作品**に授与)ほか各賞 / 賞金

## 5. スケジュール
| 期間 | 内容 |
|---|---|
| 2026-06-22(月)〜 2026-11-06(金) | プレエントリー |
| 2026-08-28(金)〜 2026-11-19(木) | 本エントリー |
| **2026-12-05(土)〜 12-06(日)** | **一次審査会** |
| 2027 年 1 月中 | ファイナリスト発表 |
| 2027-02-27(土) | 最終審査会 / 授賞式 |

## 6. 審査基準(5 項目を軸に総合評価)
1. 3D都市モデルの活用 2. アイデア 3. UI・UX・デザイン 4. 技術力 5. 実用性

## 7. 注意事項(本作品に関わるもの)
- 第三者のアイデア・知財の盗用禁止。所属機関の知財に関わる場合は事前承諾。
- 応募内容の秘匿は保証されない。選考通過時は一次審査・最終審査会への参加、受賞時の氏名・作品名公表に同意。
- 協力・協賛企業への直接交渉は不可。
- 外国ユーザーリスト非該当、外為法遵守、反社非関与。
- **第三者の同意や倫理審査が必要な提案は、関係機関の承認を得た上で応募。**(本作品は住所・登録情報を扱う。本人が登録するまで個別の家を断定表示しない設計と、デモは合成データで行う方針を資料に明記する)
- 個人情報は事務局(角川アスキー総合研究所)が管理。事前同意のうえ協賛企業とのマッチングに使われる。
